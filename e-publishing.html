Frequently Asked Questions

E-Publishing & Conversion Inquiries

What source file formats do you accept for eBook conversion?

We accept Adobe InDesign files (INDD, IDML), Microsoft Word (DOCX), print PDFs, hardcopy scanned books, QuarkXPress, LaTeX, and existing HTML or XML files. Our team handles complete font extraction, vector re-linking, and CSS cleanup.

How do you guarantee European Accessibility Act (EAA) and WCAG compliance?

Every title is audited using automated checkers (Ace by DAISY and SMART tool) and tested manually with screen readers (JAWS, NVDA, Apple VoiceOver). We enforce structured landmarks, semantic tags, complete metadata disclosures, and write contextual descriptive alt-text for all diagrams and artwork.

When should I choose Fixed Layout versus Reflowable ePUB?

Reflowable ePUB is best for novels, non-fiction, and text-centric books because reader font size and screen orientation adjust seamlessly. Fixed-layout ePUB is required for children's illustrated storybooks, comic books, graphic novels, and textbooks where the exact position of text over artwork must remain locked.

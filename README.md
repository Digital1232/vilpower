# VilPower Solutions — Multi-Page Enterprise AI Website (v2.0)

Lightning-fast, multi-page, SEO-optimized enterprise website for **VilPower Solutions** — Human-in-the-Loop AI & Enterprise Data Operations.

## 🚀 Architectural Overview
The platform is built with high-performance static HTML5 pages, shared CSS design tokens (`assets/css/style.css`), and global JavaScript handlers (`assets/js/main.js`). Every core offering has its own dedicated SEO-optimized landing page with structured schema (JSON-LD), targeted meta tags, and high-conversion pilot CTAs.

## ⚡ Speed & SEO Optimizations
- **Sub-second Loading Speed**: Pure static HTML5 with zero bloated JS framework dependencies.
- **Dedicated SEO Landing Pages**: Every page contains unique `<title>`, `<meta name="description">`, Open Graph tags, and structured JSON-LD schemas.
- **Design Aesthetics**: Dark obsidian luxury theme (`#04070e`, `#080d1a`) with frosted glassmorphic cards (`backdrop-blur-xl`, `border-white/10`) and radiant cyan/indigo lighting.

Open any page directly in your browser or run a lightweight local static server:

# VilPower Solutions — Interactive Website Wireframe (v2.0)

Presentation-ready interactive website wireframe prototype for **VilPower Solutions** — Human-in-the-Loop AI & Enterprise Data Operations.

## 🚀 Overview
VilPower Solutions connects enterprise clients worldwide (USA, UK, Europe, Australia, India) with high-precision data annotation, digital publishing, and commercial lease abstraction services powered by an impact-sourcing 95%+ rural women-led workforce in Tamil Nadu, India.

## 📋 Features & Sections
- **01 / Hero Carousel**: 3-slide auto-rotating showcase (AI Data Operations, Rural Women Empowerment, Global Enterprise Scale).
- **02 / Company Proof Metrics**: Audited track record (15+ Years, 70+ Projects, 157M+ Records, 99.7% Accuracy, 1,500+ Empowered).
- **03 / Services Overview**: AI Data Annotation (2D/3D & Voice), XML & STM Digital Publishing (JATS/BITS), Lease Abstraction, Web Research & Legal Data.
- **04 / Reasons to Choose VilPower**: Interactive accordion detailing accuracy, scalability, data security (ISO 27001 readiness), and social impact.
- **05 / Human + AI Story**: The "Digital Banyan Tree" model (Roots in rural incubation $\rightarrow$ Canopy in global delivery).
- **06 / Process Blueprint**: 5-step delivery methodology (*Understand $\rightarrow$ Pilot Batch $\rightarrow$ Scale Team $\rightarrow$ 3-Tier QA $\rightarrow$ Deliver & Support*).
- **07 / Global Reach**: Interactive world map layout highlighting major client markets.
- **08 / Conversion CTA & Pilot Request**: Lead qualification form with dynamic service-specific fields and 50-record free pilot batch request modal.
- **Operations Gallery & Lightbox**: Categorized visual showcase of infrastructure, teams, incubation classrooms, and impact events.

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript**: Fully self-contained, zero external build step required.
- **Tailwind CSS (v3.4 CDN)**: Responsive utility styling.
- **Lucide Icons**: Clean vector iconography.
- **Google Fonts**: *Work Sans*, *Source Serif 4*, and *Space Mono*.

## 💻 Quick Start
Simply open `index.html` in any modern web browser or serve it via a local static server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
